Developers/Quickstart

Developer quickstart

Inspect, evaluate, recommend, and serve PRA.

The current product CLI supports the complete qualification journey, an OpenAI-compatible Gateway, the reference Agent, report export, bundle resolution, and conservative qualification-driven serving.

Open technical quickstart ↗Browse source
01

Install and inspect the environment

Use Python 3.10 or newer. pra doctor reports the active Python, PyTorch, and device environment.

git clone https://github.com/einnovator/pdattention.git
cd pdattention
python -m pip install -e .
pra doctor
02

Inspect engines and the model pair

Capability availability does not imply qualification. Inspect the exact model and engine before running a workload.

pra engines
pra inspect Qwen/Qwen3-1.7B --engine hf
03

Create a qualification run

Use a representative dataset. Imported measurements remain explicit; missing values cannot satisfy recommendation gates.

pra evaluate Qwen/Qwen3-1.7B --engine hf \
  --dataset DATASET -o .pra/runs/first
04

Recommend and export the evidence

The report keeps quality, selected context, native representation, serving, and reuse effects separate.

pra recommend .pra/runs/first
pra report .pra/runs/first --format html
05

Serve the qualified path

auto chooses conservatively from the available evidence and never promotes a deeper mode from capability alone.

pra serve Qwen/Qwen3-1.7B --engine hf \
  --mode auto --profile recommended --explain
Existing OpenAI-compatible application

Put Selected Context in front of the endpoint you already run.

The Gateway accepts ordinary chat requests and can preserve typed resources, session identity, deltas, budgets, and explicit fallback for PRA-aware clients.

pra gateway serve \
  --mode selected-context \
  --backend vllm \
  --backend-url http://127.0.0.1:8000/v1

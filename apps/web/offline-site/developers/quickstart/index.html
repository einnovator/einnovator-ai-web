Developers/Quickstart

Developer quickstart

Run the PRA reference system in five steps.

The commands below are verified against the current public CLI and documentation. They do not assume unreleased gateway or agent commands.

01

Clone and install

Use Python 3.10 or newer.

git clone https://github.com/einnovator/pdattention.git
cd pdattention
python -m pip install -e .
02

Validate configuration

pra config validate
pra config show
03

Inspect the starter dataset

pra dataset show -g stage0_synthetic_memory -m 2
04

Train the standalone reference

pra train --steps 200
05

Evaluate PRA and baselines

pra eval
Open local documentation ↗Browse source

Documentation location: configure DOCS_URL for the deployment. The public fallback points to the open-source repository.

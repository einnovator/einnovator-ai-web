Getting started

Start with the reference runtime.

The shipping CLI currently covers configuration, datasets, training, evaluation, experiments, storage, and workers. Gateway and engine-native commands are not invented here.

python -m pip install -e .
pra config validate
pra dataset show -g stage0_synthetic_memory -m 2
pra train --steps 200
pra eval

Known limitations

  • Routing quality is model- and domain-dependent.
  • Frozen sparse memory has a depth-dependent compatibility band.
  • Serving throughput and tail latency are not the focus of the reference runtime.

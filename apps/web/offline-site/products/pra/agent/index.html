PRA Agent · Available reference application

Treat tasks, tools, results, sessions, and source records as first-class context.

PRA Agent is an optional open-source reference surface for durable agent work. The same runtime also fits existing agents through the Gateway, SDK, and typed event bridges, so adopting PRA does not require replacing the application loop.

Local operator surface

The Agent Web UI is experimental.

It uses the same profiles, sessions, records, tasks, tools, and runtime as the CLI; it is not a second agent implementation.

  • Local browser conversations, chat, task state, and record inspection
  • Typed tool-approval events scoped to one request
  • Loopback binding by default
  • No production authentication layer

Keep the Web UI on loopback unless an authenticated reverse proxy, TLS, network controls, rate limits, request limits, and audit policy are in place.

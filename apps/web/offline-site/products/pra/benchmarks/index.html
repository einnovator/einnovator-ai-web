Evidence ladder

A label is part of every claim.

Controlled

Mechanism isolation

Synthetic or bounded probes test causality, parity, routing, and memory geometry.

Model-backed

Pretrained behavior

Pinned model runs test routing and memory consumption under real model semantics.

Natural workload

Dataset behavior

Natural QA or application-shaped records add ambiguity and multi-hop structure.

Serving

Runtime economics

Online latency, throughput, memory, transfers, reuse, and tails complete qualification.

The system

Logical memory stays large. Active context stays bounded.

PRA separates what an application can address from what a model must process in the current operation.

01

Keep context addressable

Store documents, records, tool results, task state, and history as typed resources with stable identities.

02

Route before materializing

Use compact semantic and symbolic addresses to select relevant resources under an explicit budget.

03

Bring back exact detail

Materialize selected text through a gateway or selected native K/V in qualified engine integrations.

Adopt incrementally

Start at the integration depth your evidence supports.

The deepest integration is not automatically the best one. Begin with selected text, measure your workload, then move deeper only when native reuse pays.

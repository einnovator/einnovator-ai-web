PRA Agent · Reference application

Treat tasks, tools, results, sessions, and source records as first-class context.

PRA Agent is an optional reference surface for long-running work. PRA also fits existing agents through the Gateway and SDK, so adopting context selection does not require replacing the application loop.

Compatibility

Use an existing agent or the reference surface.

Selected Context is ordinary text at the model boundary. Typed resources and qualified native integrations are optional upgrades with explicit fallback.

  • Gateway path for OpenAI-compatible applications
  • SDK path for direct record and selection control
  • Authorization remains independent of retrieval relevance
  • No raw native memory on the agent-facing wire

The public CLI reviewed for this site does not yet expose a generally available agent command. This page describes the product direction without presenting it as shipping.

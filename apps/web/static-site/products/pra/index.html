Products/PRA

PRA · Open source

A context layer for AI systems that need more than a bigger prompt.

PRA keeps reusable context addressable outside the active prompt, routes to relevant resources, and materializes selected detail through a compatible or native inference path.

Try PRA ↗View benchmarks
Why PRA

Separate logical context from active model context.

Long-running agents accumulate documents, tool outputs, sessions, tasks, and state. PRA makes that memory explicit and selectively visible instead of replaying everything on every turn.

Bound the active set

Selection budgets control the text or K/V admitted to the current operation.

Preserve exact backing detail

Compact views guide discovery while lossless source remains available for materialization.

Choose the execution depth

Begin with E0 selected text. Qualify E2 or E3 only where native reuse changes the frontier.

Keep engines replaceable

Logical records and policies stay separate from engine-specific physical memory.

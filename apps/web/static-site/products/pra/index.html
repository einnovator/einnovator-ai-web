Products/PRA

PRA · Open source

Context infrastructure for agents that cannot keep replaying everything.

PRA keeps documents, tool results, tasks, sessions, and exact backing records addressable outside the prompt, then selects the relevant, authorized detail for each request.

Try PRA ↗View benchmarks
Why PRA

Separate what an application can address from what a model must process.

Long-running applications accumulate far more context than every request needs. PRA makes that working set explicit, typed, scoped, selectable, and recoverable.

Typed records

Documents, tools, results, tasks, and sessions retain stable identities and scopes.

Bound selection

Policies choose relevant context under an explicit request budget.

Exact backing detail

Compact views guide discovery while authoritative source records remain available.

Profiles and fallback

Qualified settings bind quality gates to a reversible ordinary-text path.

Product paths

Send less. Recompute less. Manage reuse.

Start with Selected Context on the server you already use. Native paths are optional and earn adoption through measurement.
